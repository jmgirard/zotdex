# M100: Keep a plugin's last good record

**Status:** done (2026-11-05, PR #844 https://github.com/jmgirard/zotero-plugin-index/pull/844)

**Goal:** A plugin that a build cannot read for a build-level reason keeps its last read facts on the site for up to 7 days, marked as older data.

**Outcome:** `pnpm build --previous <url>` reads the deployed data with `readPrevious` (`src/build/previous.ts`, moved from `carry.ts`, 60 s and 16 MiB) after the source read and before `countReports`, only when a record has a build-level failure. `keptFacts` in `src/build/keep.ts` gives such a record the deployed `upstream` and `startTests` with an optional `kept` field (`readAt`, `failure`) when the deployed list names the id once, the `repoUrl` matches, the record passes the schema, and `readAt` is at most `KEEP_MS` (7 days) before `generatedAt` and not after it; the written record must pass the schema too. A kept record stays build-level and counts as failed in both deploy bars (`src/build/cli.ts`), gets no start plan item, keeps its start results through `addResults`, and `carryResults` carries none from it. The schema adds `kept` with a dependency on `upstream` and stays v1. The home row shows an "Older data" badge after any "Archived" badge, the legend names it, the plugin page says "The build that wrote this page, on <day>, could not read this plugin" with the failure and the day of the kept facts, About gains an "Older data" section, and the footer reads "The data comes from the build of <day>." `build.yml` passes `--previous`. Branch run 42110419077 passed in 26:18; a hand run over all 736 entries with every read cut kept 502 of 502 deployed records.

**Decisions:** D-066 (keep deployed facts for 7 days on a build-level failure, annotating D-011, D-012, D-015, D-023, D-035). The user kept the deploy bar at more than half, chose the home badge and the page note, and granted the branch and main build runs.

Row "Keep a plugin's last good record" graduated. Lesson 2026-10-26 (M014) evicted by rank for the new M100 lesson. No row unparked.
