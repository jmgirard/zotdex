# M105: Offer plugin authors a README badge

**Status:** done (2026-11-06, PR #849 https://github.com/jmgirard/zotdex/pull/849)

**Goal:** Give each listed plugin a README badge, labeled Zotdex, that says which Zotero majors its release started in and links to its page on the index, so authors who add it send readers to Zotdex (D-071).

**Outcome:** `badgeFor` in `src/site/badge.ts` gives a shields.io endpoint object, label `Zotdex`, `cacheSeconds` 3600: "started in Zotero " and each major that `startTests` names whose newest result is `started`, sorted by number and joined by " · ", in `#1d5fb8`; else "no start in tests", "not start-tested", or "no data" in `lightgrey`; a kept record reads like any other. `majorStart` moved to `src/site/version.ts`, typed by shape, and `site/src/data.ts` re-exports it. `site/src/pages/badges/[id].json.ts` writes `badges/<raw id>.json` per record. Each plugin page ends with a `data-section="badge"` card, "Badge for your README", whose one `<code>` holds `badgeSnippet`'s Markdown (`site/src/data.ts`), styled as `.badge-snippet`; the site loads nothing from shields.io. README, About's "README badge" section, DESIGN's Contract boundary, and CHANGELOG describe the messages, the caches, failed start days, and removal. After the merge, build run 42169269027 deployed; `badges/zoteropdftranslate@euclpts.com.json` answers 200 with `max-age=600`, and shields.io drew "Zotdex: started in Zotero 8 · 9 · 10" in `#1d5fb8` with `max-age=3600`.

**Decisions:** D-071 (the badge address is a stable public path, the badge states starts only, and a kept record shows the same badge at the user's choice).
