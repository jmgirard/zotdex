# M103: Move the site to zotdex.jmgirard.com and name it Zotdex

**Status:** done (2026-11-05, PR #847 https://github.com/jmgirard/zotero-plugin-index/pull/847)

**Goal:** Serve the site and its data at `https://zotdex.jmgirard.com/` under the name Zotdex before the index is advertised, with GitHub forwarding the old github.io addresses there (D-069).

**Outcome:** `ORIGIN` in `site/src/base.ts`, `PREVIOUS_URL` in `src/build/previous.ts`, both `--previous` lines in `build.yml`, and each published schema's `$id` name `https://zotdex.jmgirard.com`. A site test over every built page checks the site name, the titles, and that `zotero plugin index`, in any case, appears only in the home title and `og:title`. README opens "Zotdex is a community index", DESIGN's purpose line names Zotdex in the repo zotero-plugin-index, and the CHANGELOG Unreleased entry from M102 now names the final address. After the merge the custom domain changed to zotdex, the certificate came in about 60 s, HTTPS is enforced, and build run 42154660841 deployed: `carry-start-results` read the new URL and carried 1673 start results. The old github.io address answers 301 to the same path and query on zotdex; `zotero-plugins.jmgirard.com` no longer answers and its DNS record is gone. The repo homepage names zotdex. The repo keeps its name for now.
