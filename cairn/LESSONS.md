# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Limits: at most 25
lessons, each at most 450 bytes. Over the limits, retire, shorten, or split
lessons first. Then the lowest-ranked lesson leaves first. Rank is the newest
milestone in a lesson's provenance, and reviews mark `used M<NNN>` on the
lessons a milestone used. Corrected in place when proven false (never append a
correction).

- 2026-10-25 (M001, used M100, corrected 2026-10-30): pnpm is not installed on the maintainer's machine, so run it as `npx -y pnpm@12.15.0`. Many test files, such as the check, build, and site tests, spawn pnpm through `npm_execpath`, so run them with `pnpm test`, not bare `vitest`. The 60 s test timeout covers a first check run, which can wait 30 s to download the registry schema.
- 2026-10-26 (M015, used M100, corrected 2026-10-30): The built-in browser pane cannot screenshot or read a `file://` page. To view a built site, add a `.claude/launch.json` entry running `python3 -m http.server <port> --directory <dir>` with the site at `<dir>/zotero-plugin-index/` so Pages-path links resolve, keep the file out of git through `.git/info/exclude`, then `preview_start` it. `resize_window`'s `colorScheme` sets either scheme there.
- 2026-10-26 (M018, used M098, corrected M020): README, CHANGELOG, and DESIGN wrap prose near 76 columns, so `grep` for a phrase misses one split across lines. Search a joined copy: `tr '\n' ' ' < README.md | sed 's/  */ /g' | grep -o '<phrase>' | wc -l`. The joined copy is one line, so `grep -c` prints at most 1. Also strip `//` or `#` comment marks for code comments.
- 2026-10-27 (M021, used M098): An Astro template drops the line break between text and an element on the next line, so "Report that it" then `<a>Works</a>` rendered as "itWorks". Write `{" "}` at the line end. Read the built page's text, not only the template, since the site tests match markup. A test that strips tags must add no space for them, or it hides the dropped one.
- 2026-10-27 (M027, used M092): `npx -y pnpm@12.15.0 exec vitest` once hung 7 minutes inside npm before Vitest started. A test file that spawns no pnpm, such as `test/upstream.test.ts`, also runs as `./node_modules/.bin/vitest run <file>`, which starts in seconds; the spawn tests still need `pnpm test`.
- 2026-10-28 (M035, used M100): A local `dist/v1/plugins.json` can predate newer data fields, so a site built from it showed a language menu with no options. For a hand check of the real site, download the deployed `https://jmgirard.github.io/zotero-plugin-index/v1/plugins.json` into `<dir>/v1/`, then run `pnpm site --out <dir>`.
- 2026-10-28 (M036, used M100): An Edit whose old text ends before a line's end leaves the rest of that line joined to the last new line, so rewrapping README or CHANGELOG prose left lines of 94 to 129 characters. End the old text at a line break, then list long added lines: `git diff -U0 main | grep '^+' | awk 'length > 80'`.
- 2026-10-29 (M048, used M098): To check page width at several sizes in the browser pane without resizing it, load each page in a same-origin `<iframe>` of that width from one `javascript_tool` call and compare `contentDocument.documentElement.scrollWidth` with `clientWidth`. Set `border: 0`, since the default border makes a 375 px iframe's viewport 371 px. Append a 900 px `<div>` once to see the check fail.
- 2026-10-29 (M054, used M098): The layout sets `overflow-wrap: anywhere` on `body`, so a narrow table header broke mid-word ("Zo ter o") at 375 px while the iframe width check still passed. Set `overflow-wrap: normal` on a table so its words break only at spaces, and look at the 375 px view in the browser pane, since the width check cannot see a broken word.
- 2026-10-30 (M061, used M100): `upstream.repoUrl` is always GitHub's `html_url`, so a site-fixture case for an odd repo URL (a query, a GitLab host, `http:`) belongs on a failure record, whose `repoUrl` comes from a hand-typed `meta.json`; on an upstream record it builds pages GitHub never yields, such as a `…#readme/releases` link. `test/site.test.ts` lists every fixture id in home order by hand in three tests, so a new record goes into each.
- 2026-10-30 (M063, used M099): `cssRules` in `test/site.test.ts` drops `@media` wrappers, so a rule inside `@media (forced-colors: active)` reads as another rule of that selector; to test a media block, match the layout source with a regex that names the query. Forced colors compute `background-image` to `none` unless it holds a `url()`, so a control drawn with gradients needs a forced-colors fallback, as the language menu's `appearance: auto`.
- 2026-10-31 (M066, used M100): A merge to `main` deploys nothing: only `Build data` deploys, daily at 06:17 UTC. After a merge that changes `site/`, `src/site/`, `src/build/`, or the data format, offer to run `gh workflow run build.yml --ref main`. The run takes up to 30 minutes, and a failed build leaves the last good site published.
- 2026-11-02 (M075, used M100): `test/build.test.ts` compares build output with a fixed file, and `pluginRepo` feeds that build, so a new repo field in that helper fails it. Add such a field as optional, and set it only in the tests that need it. A name-match test whose repo has no `stars` or `repoGit` answers holds as unread, so it says nothing about the copy tests.
- 2026-11-02 (M079, used M098): The browser pane can be hidden while a check runs, and `requestAnimationFrame` then never fires, so a `javascript_tool` call that awaits it times out at 45 s. Wait with `setTimeout` before a width read. `browser_batch` takes at most 25 actions, so split a check of many pages into several batches.
- 2026-11-02 (M081, used M089): `test/fixtures/site/plugins.json` keeps some arrays on one line, so a `json.dump` rewrite reformats about 140 lines; add a fixture field by a text edit. GraphQL's `object(expression: "HEAD:")` tree read is slow: 18 batches of 40 repos took 69 seconds, about 4 seconds a batch, so give such a read a limit from a live run.
- 2026-11-02 (M082, used M100): `pnpm test` stops at `tsc` on a type error and prints no `Tests` line, and a pipe hides its exit code, so `pnpm test | grep Tests && git commit` committed a type error. Send the run to a file, read `$?`, then search the file.
- 2026-11-02 (M082, used M090): A GraphQL read of many repos can lose a whole batch: batches of 30 repos with 8 file expressions lost 120 of 671 repos. Read each repo's SHA and tree first, then ask for `<sha>:<file>` blobs in batches of 20, and retry the lost ones at sizes of 4 and 1. That read all 846 READMEs of 695 repos.
- 2026-11-03 (M085, used M089): Each discover run's log holds its report, so a refused repo's reason lasts as long as GitHub keeps the log. `gh run view <id> --log | cut -f3- | cut -c29-` gives the JSON, then search `"failure": "entry-exists"`. A row that says a count is not read can be read this way before a plan; this read found 4 far larger repos refused. `fixtureFetch` answers 404 for an unrecorded URL, so record each new read in a test.
- 2026-11-03 (M087, used M100): `gh run view --log` refuses until the whole run ends, but `gh api --allow-escape-sequences repos/<repo>/actions/jobs/<id>/logs` reads a done job's log sooner. A `run:` line with `Authorization: Bearer` unquoted is bad YAML, which GitHub reports as no `workflow_dispatch` trigger. The 64 KiB stdout test in `test/build.test.ts` needs over 88 KiB of output; remove the flush in `src/build/cli.ts` once to see it fail.
- 2026-11-03 (M089, used M092): Before a new rule marks a category assignment wrong, search `cairn/references/category-ledger.md` for like plugins: M089's first read marked 6 `ai` assignments wrong that its marks call right. A description override reads in the index's voice and has no `version`, so leave out a README's privacy or safety assurances and any feature that it marks unreleased.
- 2026-11-03 (M091, used M092): A lookbehind written for one phrase can cut right uses that no record shows: `(?<!\bin )\bsync` cut "Built-in sync". So run right sentences through a narrowed pattern, not only the data. A frozen-rules read of 100 unseen plugins moved the wrong rate from 13.7% to 13.5%, so id lists fix the plugins read, and pattern tuning barely helps new ones.
- 2026-11-04 (M092): To score a rule on existing marks, keep its `pattern` and add a second test, so every match already has a mark, and give its author a folder with the held-out ids and id lists removed. A regex of many alternatives can be cubic, so time a crafted long text before trusting a length cap. `gh pr merge` can print a connection reset after it merged, so read `gh pr view --json state` before a retry.
- 2026-11-05 (M097, used M098): Past Vite's 4 KiB `assetsInlineLimit`, Astro moves a module script to a file, and `homeScript` in `test/site.test.ts` then fails on a null regex; `site/astro.config.ts` sets 32768. Node and a browser's `localeCompare` order CJK ties differently, so to return to the built order keep the built rows, and do not sort again.
- 2026-11-05 (M098): A px media query ignores the browser's text size while rem-sized controls grow, so at 24 px text a 1000 px step left the search box 87 px wide. Use rem steps for rem-sized layout. To test, launch Chromium with `--blink-settings=defaultFontSize=24`, since a style tag on `html` moves the controls but not rem media queries. An `overflow: hidden` on a card hides what grows past it with no way to scroll to it.
- 2026-11-05 (M100): On the maintainer's machine python3's urllib fails HTTPS certificate checks, so read the deployed data with curl or a short node script that imports `src/` directly. The Bash tool runs zsh, where `echo ===` fails as an `=` expansion and a glob that matches nothing, such as `rm -rf dir/*` on an empty dir, stops the command.
