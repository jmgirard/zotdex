# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Limits: at most 25
lessons, each at most 450 bytes. Over the limits, retire, shorten, or split
lessons first. Then the lowest-ranked lesson leaves first. Rank is the newest
milestone in a lesson's provenance, and reviews mark `used M<NNN>` on the
lessons a milestone used. Corrected in place when proven false (never append a
correction).

- 2026-10-25 (M001, used M079, corrected 2026-10-30): pnpm is not installed on the maintainer's machine, so run it as `npx -y pnpm@12.15.0`. Many test files, such as the check, build, and site tests, spawn pnpm through `npm_execpath`, so run them with `pnpm test`, not bare `vitest`. The 60 s test timeout covers a first check run, which can wait 30 s to download the registry schema.
- 2026-10-26 (M014, used M079): `pnpm test -- --reporter=verbose` hands `--` to Vitest, which reads the rest as a file filter and prints no test names. For per-test names, run `npx -y pnpm@12.15.0 exec vitest run --reporter=verbose` after `pnpm test`. `pnpm exec` still sets `npm_execpath`, so the spawn tests run.
- 2026-10-26 (M015, used M079, corrected 2026-10-30): The built-in browser pane cannot screenshot or read a `file://` page. To view a built site, add a `.claude/launch.json` entry running `python3 -m http.server <port> --directory <dir>` with the site at `<dir>/zotero-plugin-index/` so Pages-path links resolve, keep the file out of git through `.git/info/exclude`, then `preview_start` it. `resize_window`'s `colorScheme` sets either scheme there.
- 2026-10-26 (M018, used M079, corrected M020): README, CHANGELOG, and DESIGN wrap prose near 76 columns, so `grep` for a phrase misses one split across lines. Search a joined copy: `tr '\n' ' ' < README.md | sed 's/  */ /g' | grep -o '<phrase>' | wc -l`. The joined copy is one line, so `grep -c` prints at most 1. Also strip `//` or `#` comment marks for code comments.
- 2026-10-27 (M021, used M079): An Astro template drops the line break between text and an element on the next line, so "Report that it" then `<a>Works</a>` rendered as "itWorks". Write `{" "}` at the line end. Read the built page's text, not only the template, since the site tests match markup. A test that strips tags must add no space for them, or it hides the dropped one.
- 2026-10-27 (M027, used M078): `npx -y pnpm@12.15.0 exec vitest` once hung 7 minutes inside npm before Vitest started. A test file that spawns no pnpm, such as `test/upstream.test.ts`, also runs as `./node_modules/.bin/vitest run <file>`, which starts in seconds; the spawn tests still need `pnpm test`.
- 2026-10-28 (M035, used M079): A local `dist/v1/plugins.json` can predate newer data fields, so a site built from it showed a language menu with no options. For a hand check of the real site, download the deployed `https://jmgirard.github.io/zotero-plugin-index/v1/plugins.json` into `<dir>/v1/`, then run `pnpm site --out <dir>`.
- 2026-10-27 (M030, used M072): Vitest's fake timers do not replace the timer behind `execFile`'s `timeout`, so test a git limit with a short real limit and a `PATH` shim that runs `exec sleep 600`. For a `performance.now()` limit, `vi.spyOn(performance, "now")` and move its value from `fixtureFetch`'s `onRequest` on the stalled URL, so the cut needs no real wait.
- 2026-10-28 (M036, used M079): An Edit whose old text ends before a line's end leaves the rest of that line joined to the last new line, so rewrapping README or CHANGELOG prose left lines of 94 to 129 characters. End the old text at a line break, then list long added lines: `git diff -U0 main | grep '^+' | awk 'length > 80'`.
- 2026-10-29 (M048, used M078): To check page width at several sizes in the browser pane without resizing it, load each page in a same-origin `<iframe>` of that width from one `javascript_tool` call and compare `contentDocument.documentElement.scrollWidth` with `clientWidth`. Set `border: 0`, since the default border makes a 375 px iframe's viewport 371 px. Append a 900 px `<div>` once to see the check fail.
- 2026-10-29 (M054, used M078): The layout sets `overflow-wrap: anywhere` on `body`, so a narrow table header broke mid-word ("Zo ter o") at 375 px while the iframe width check still passed. Set `overflow-wrap: normal` on a table so its words break only at spaces, and look at the 375 px view in the browser pane, since the width check cannot see a broken word.
- 2026-10-30 (M060, used M078, corrected M078): An Astro page can carry a tested function in a classic `<script is:inline set:html={text}>` whose frontmatter text holds `${fn}`: the site build strips its types and comments and does not minify it, so the function must call and read nothing outside its body except built-ins and browser globals, as `prePaintStyle` in `src/site/home-filter.ts` does. A site test runs the built script in `node:vm`.
- 2026-10-30 (M061, used M079): `upstream.repoUrl` is always GitHub's `html_url`, so a site-fixture case for an odd repo URL (a query, a GitLab host, `http:`) belongs on a failure record, whose `repoUrl` comes from a hand-typed `meta.json`; on an upstream record it builds pages GitHub never yields, such as a `…#readme/releases` link. `test/site.test.ts` lists every fixture id in home order by hand in three tests, so a new record goes into each.
- 2026-10-30 (M063, used M078): `cssRules` in `test/site.test.ts` drops `@media` wrappers, so a rule inside `@media (forced-colors: active)` reads as another rule of that selector; to test a media block, match the layout source with a regex that names the query. Forced colors compute `background-image` to `none` unless it holds a `url()`, so a control drawn with gradients needs a forced-colors fallback, as the language menu's `appearance: auto`.
- 2026-10-31 (M066, used M078): A merge to `main` deploys nothing: only `Build data` deploys, daily at 06:17 UTC. After a merge that changes `site/`, `src/site/`, `src/build/`, or the data format, offer to run `gh workflow run build.yml --ref main`. The run takes up to 30 minutes, and a failed build leaves the last good site published.
- 2026-10-31 (M069): `actions/upload-artifact@v7` leaves out hidden files (`include-hidden-files` defaults to false) and drops every directory from its file list, so an empty folder never uploads. The site job's `pnpm data-digest --expect` counts both, so a dotfile or empty folder in `dist/` fails every honest deploy. Read the action's `src/shared/search.ts` at its tag before saying what an upload keeps; M069's first read got directories wrong.
- 2026-10-31 (M069, used M071): In `test/workflows.test.ts`, `job.indexOf("<command>")` finds the first mention, which can be a comment above every step, so an order check passes wherever the step sits. Anchor on the run line, such as `"          pnpm carry-start-results --plan "`, and plant the step out of order once to see the test fail.
- 2026-10-31 (M070, used M079): `JSON.parse` keeps a `__proto__` key as an own property, but `obj[key] = value` with that key on a `{}` sets the object's prototype, so a forged state file hid a repo through inherited keys. Copy parsed records into `Object.create(null)` and keep only keys of the expected shape. In tests, `fixtureFetch` answers the nth POST to one URL from `POST <url> #<n>`, so each GraphQL batch gets its own answer.
- 2026-11-02 (M074, used M077): The reader follows redirects, so the host that `update_url` names need not be where the file is: `forrtproject.github.io/flora-zotero/update.json` answers 301 to `forrt.org`. Before a plan rests on a URL's host, request the real URLs: `curl -sSL -o /dev/null -w '%{num_redirects} %{url_effective}\n' <url>`.
- 2026-11-02 (M075, used M077): `test/build.test.ts` compares build output with a fixed file, and `pluginRepo` feeds that build, so a new repo field in that helper fails it. Add such a field as optional, and set it only in the tests that need it. A name-match test whose repo has no `stars` or `repoGit` answers holds as unread, so it says nothing about the copy tests.
- 2026-11-02 (M079): The browser pane can be hidden while a check runs, and `requestAnimationFrame` then never fires, so a `javascript_tool` call that awaits it times out at 45 s. Wait with `setTimeout` before a width read. `browser_batch` takes at most 25 actions, so split a check of many pages into several batches.
