# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Limits: at most 25
lessons, each at most 450 bytes. Over the limits, retire, shorten, or split
lessons first. Then the lowest-ranked lesson leaves first. Rank is the newest
milestone in a lesson's provenance, and reviews mark `used M<NNN>` on the
lessons a milestone used. Corrected in place when proven false (never append a
correction).

- 2026-10-25 (M001, used M116, corrected 2026-10-30): pnpm is not installed on the maintainer's machine, so run it as `npx -y pnpm@12.15.0`. Many test files, such as the check, build, and site tests, spawn pnpm through `npm_execpath`, so run them with `pnpm test`, not bare `vitest`. The 60 s test timeout covers a first check run, which can wait 30 s to download the registry schema.
- 2026-10-26 (M015, used M115, corrected 2026-10-30, corrected M102): The built-in browser pane cannot screenshot or read a `file://` page. To view a built site, add a `.claude/launch.json` entry running `python3 -m http.server <port> --directory <dir>` with the site at the top of `<dir>`, keep the file out of git through `.git/info/exclude`, then `preview_start` it. `resize_window`'s `colorScheme` sets either scheme there.
- 2026-10-26 (M018, used M116, corrected M020, corrected M107): `docs/*.md`, CHANGELOG, and DESIGN wrap prose near 76 columns, so `grep` for a phrase misses one split across lines. Search a joined copy: `tr '\n' ' ' < docs/data.md | sed 's/  */ /g' | grep -o '<phrase>' | wc -l`. The joined copy is one line, so `grep -c` prints at most 1. Also strip `//` or `#` comment marks for code comments.
- 2026-10-27 (M021, used M115): An Astro template drops the line break between text and an element on the next line, so "Report that it" then `<a>Works</a>` rendered as "itWorks". Write `{" "}` at the line end. Read the built page's text, not only the template, since the site tests match markup. A test that strips tags must add no space for them, or it hides the dropped one.
- 2026-10-28 (M035, used M115, corrected M102, corrected M103): A local `dist/v1/plugins.json` can predate newer data fields, so a site built from it showed a language menu with no options. For a hand check of the real site, download the deployed `https://zotdex.jmgirard.com/v1/plugins.json` into `<dir>/v1/`, then run `pnpm site --out <dir>`.
- 2026-10-28 (M036, used M116): An Edit whose old text ends before a line's end leaves the rest of that line joined to the last new line, so rewrapping docs or CHANGELOG prose left lines of 94 to 129 characters. End the old text at a line break, then list long added lines: `git diff -U0 main | grep '^+' | awk 'length > 80'`.
- 2026-10-29 (M048, used M115): To check page width at several sizes in the browser pane without resizing it, load each page in a same-origin `<iframe>` of that width from one `javascript_tool` call and compare `contentDocument.documentElement.scrollWidth` with `clientWidth`. Set `border: 0`, since the default border makes a 375 px iframe's viewport 371 px. Append a 900 px `<div>` once to see the check fail.
- 2026-10-30 (M061, used M114): `upstream.repoUrl` is always GitHub's `html_url`, so a site-fixture case for an odd repo URL (a query, a GitLab host, `http:`) belongs on a failure record, whose `repoUrl` comes from a hand-typed `meta.json`; on an upstream record it builds pages GitHub never yields, such as a `…#readme/releases` link. `test/site.test.ts` lists every fixture id in home order by hand in three tests, so a new record goes into each.
- 2026-10-30 (M063, used M108): `cssRules` in `test/site.test.ts` drops `@media` wrappers, so a rule inside `@media (forced-colors: active)` reads as another rule of that selector; to test a media block, match the layout source with a regex that names the query. Forced colors compute `background-image` to `none` unless it holds a `url()`, so a control drawn with gradients needs a forced-colors fallback, as the language menu's `appearance: auto`.
- 2026-10-31 (M066, used M116): A merge to `main` deploys nothing: only `Build data` deploys, daily at 06:17 UTC. After a merge that changes `site/`, `src/site/`, `src/build/`, or the data format, offer to run `gh workflow run build.yml --ref main`. The run takes up to 30 minutes, and a failed build leaves the last good site published.
- 2026-11-02 (M075, used M115): `test/build.test.ts` compares build output with a fixed file, and `pluginRepo` feeds that build, so a new repo field in that helper fails it. Add such a field as optional, and set it only in the tests that need it. A name-match test whose repo has no `stars` or `repoGit` answers holds as unread, so it says nothing about the copy tests.
- 2026-11-02 (M079, used M115): The browser pane can be hidden while a check runs, and `requestAnimationFrame` then never fires, so a `javascript_tool` call that awaits it times out at 45 s. Wait with `setTimeout` before a width read. `browser_batch` takes at most 25 actions, so split a check of many pages into several batches.
- 2026-11-02 (M082, used M116): `pnpm test` stops at `tsc` on a type error and prints no `Tests` line, and a pipe hides its exit code, so `pnpm test | grep Tests && git commit` committed a type error. Send the run to a file, read `$?`, then search the file.
- 2026-11-03 (M087, used M116): `gh run view --log` refuses until the whole run ends, but `gh api --allow-escape-sequences repos/<repo>/actions/jobs/<id>/logs` reads a done job's log sooner. A `run:` line with `Authorization: Bearer` unquoted is bad YAML, which GitHub reports as no `workflow_dispatch` trigger. The 64 KiB stdout test in `test/build.test.ts` needs over 88 KiB of output; remove the flush in `src/build/cli.ts` once to see it fail.
- 2026-11-05 (M098): A px media query ignores the browser's text size while rem-sized controls grow, so at 24 px text a 1000 px step left the search box 87 px wide. Use rem steps for rem-sized layout. To test, launch Chromium with `--blink-settings=defaultFontSize=24`, since a style tag on `html` moves the controls but not rem media queries. An `overflow: hidden` on a card hides what grows past it with no way to scroll to it.
- 2026-11-05 (M100, used M115): On the maintainer's machine python3's urllib fails HTTPS certificate checks, so read the deployed data with curl or a short node script that imports `src/` directly. The Bash tool runs zsh, where `echo ===` fails as an `=` expansion and a glob that matches nothing, such as `rm -rf dir/*` on an empty dir, stops the command.
- 2026-11-05 (M101): The `pnpm build` log prints read times that differ from run to run, so a test that compares two runs' stdout drops them with `untimed` and compares `timedCount` in `test/build.test.ts`. A `readMs` of 300 ms in `buildData` tests also cuts the Better Notes fixture read, so a stall test needs about 3000 ms.
- 2026-11-05 (M104): After a GitHub Pages change, the github.io edge cache kept an old 301 for about an hour, and a query string did not get past it on that path. Read `age` and `x-cache` in `curl -sI` and wait it out before writing what an old address answers. A router also caches a missing DNS record for the zone's SOA minimum (1800 s on Cloudflare), so look up a new record only after adding it, or ask `@1.1.1.1`.
- 2026-11-06 (M108, used M114): The browser pane caps its screenshot frame near 800 px, so at a 1280 px viewport a zoom is at 62.5% and cannot show a 3 px detail. To zoom a wide layout at full size, set a 375 px viewport, load the page in a same-origin `<iframe>` 1280 px wide at `left: -120px`, and zoom there. The theme button's dark choice on a dark system clears `data-theme`, so read a computed fill, not the attribute.
- 2026-11-07 (M109, used M114, corrected M110): Astro writes an apostrophe as `&#39;` in text that an expression inserts, such as a `data.ts` constant, but leaves template text and an attribute such as `title={…}` as typed, so a site test unescapes the one and not the other. A date shown from `generatedAt` needs `timeZone: "UTC"`, and only a time just after midnight UTC, checked in a western time zone, shows a missing one.
- 2026-11-07 (M113): A CSS grid keeps its `column-gap` beside an `auto` track that holds nothing, so a two-column `.page-head` cut the head text by 24 px on every page without an icon. Put the space on the side column's margin, and measure a page without the optional column too. sharp draws an SVG's `data:` image but no file path or URL link, and `limitInputPixels` bounds only the outer SVG.
- 2026-11-07 (M114): `gitRunner`'s `bytes` in `src/discover/propose.ts` writes any `input` to git's stdin, so `""` sent to a git command that reads none, such as `cat-file blob`, can fail as an unhandled `write EPIPE` when git exits first. Every test passed and one of two CI runs of the commit failed, so pass no input there. A plant restored with `git checkout -- <file>` also drops that file's uncommitted edits: restore from a copy.
- 2026-11-07 (M115, used M116): `pnpm test -- <flags>` does not reach Vitest, since the script is `tsc --noEmit && vitest run`. For test names, run `pnpm exec vitest run <file> --reporter=verbose`; the site tests that spawn pnpm still work there, since `pnpm exec` sets `npm_execpath`.
- 2026-11-07 (M115, used M116): curl gets a Cloudflare page from docs.clamav.net, and docs.virustotal.com's terms page redirects to Google Cloud's terms, so read those with a web fetch tool. A readme.io page such as docs.virustotal.com gives its raw text with `.md` added to its path. ClamAV runs only in CI: no `clamscan` or `freshclam` is on the maintainer's machine.
- 2026-11-07 (M116): A `Build data` run dispatched on a branch runs every job but the deploy, so a scan or build change can be measured before its merge: `gh workflow run build.yml --ref <branch> -f malware-scan=true`, then read the job log with `gh api --allow-escape-sequences repos/jmgirard/zotdex/actions/jobs/<id>/logs`. The branch must be pushed first.
